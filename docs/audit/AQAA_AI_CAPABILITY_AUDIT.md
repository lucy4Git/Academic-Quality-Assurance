### 1.3 Vector Store / RAG Retrieval

**Status:** BROKEN (placeholder mode)

Critical finding confirmed through live API test:

```json
{
  "answer": "...",
  "is_placeholder_mode": true,
  "message": "hash-based placeholder embeddings, not semantic embeddings"
}
```

- Qdrant is running and populated with knowledge documents
- Documents are indexed with **hash-based placeholder vectors**, not real semantic embeddings
- Vector similarity search returns documents based on hash proximity, not semantic relevance
- This means the "Advanced RAG + Citation Verification" (Phase 3 Sprint 3) does not perform semantic retrieval
- The LLM still generates responses, but the retrieved context passed to it is not semantically relevant

**Impact:** AI answers are generated by a real LLM but without meaningful grounding in the knowledge base. The "citations" shown may not be semantically relevant to the question asked.

**Status:** PARTIALLY_IMPLEMENTED

```
Web Source → Acquisition Engine → Crawl → Extraction Engine → Content → Qdrant
```

- **Acquisition**: `SourceRegistrar`, `CrawlScheduler`, robots.txt compliance, rate limiting — code complete
- **Extraction**: `ExtractionEngine`, BS4 dual-guard — code complete; BS4 bug fix committed
- **Indexing**: Documents reach Qdrant, but indexed with hash embeddings, not semantic vectors

The pipeline is structurally complete but the indexing step is broken at the semantic level.

## 6. Required to Fix AI Capabilities

In priority order:

1. **Replace hash embeddings with real embedding model** — Index all documents in Qdrant using a real embedding model (OpenAI `text-embedding-3-small`, Google `text-embedding-004`, or equivalent). This is the single highest-impact fix for AI quality.
2. **Wire `GET /api/v1/knowledge-search`** — Fix the 405 error (wrong HTTP method or unmounted route).
3. **Verify all 8 audit agents** — Only Module Folder Audit was live-tested. Others should be exercised.
4. **Test SSE streaming end-to-end** — `ask-stream` endpoint not confirmed in this audit.
5. **Verify conversation history persistence** — AI chat tables exist but read path not confirmed.
