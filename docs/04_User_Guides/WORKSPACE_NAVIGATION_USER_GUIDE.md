# Workspace Navigation — User Guide

**Document ID:** UG-NAV-001
**Status:** Active
**Introduced:** Split 1 (2026-07-06)

---

## What changed

The left sidebar has been simplified from eight labelled sections into a single
list of seven **workspaces**. Each workspace is a landing page that groups the
related tools behind it, so you reach any feature in at most two clicks.

## The seven workspaces

| Workspace | Icon | Who sees it | What's inside |
|-----------|------|-------------|---------------|
| **Home** | House | Everyone | Executive overview: quality KPIs and quick actions. |
| **Institution** | Building | QA Officer and above | Institutions, Faculties, Departments, Programmes, Modules. |
| **Quality** | Shield-check | Coordinator and above | File Library, Upload Evidence, Audit Centre, Findings, Workflow, Approvals, Accreditation. |
| **Knowledge** | Book | Staff | Knowledge Review, Knowledge Search, IKP Management. |
| **AI** | Brain | Staff | AI Workspace, AI QA Assistant, Qualification Intelligence, Institution Workspace. |
| **Analytics** | Bar chart | HOD and above | Analytics and Reports. |
| **Administration** | Gear | System Admin | Users, System Settings, AI Providers. |

> "Staff" means every role except Student. Students have no sidebar access to
> these workspaces.

## How role visibility works

- The sidebar only shows workspaces your role can open.
- Inside each workspace, the cards you see are also filtered by role — e.g. a
  Programme Coordinator opening **Institution** will see Programmes and Modules
  but not Institutions or Faculties.
- Page-level access is still enforced by the server; the sidebar simply hides
  what you cannot use.

## Finding a specific tool

| I want to… | Go to |
|------------|-------|
| Run an AI audit | Quality → Audit Centre |
| Upload evidence | Quality → Upload Evidence |
| Search policies | Knowledge → Knowledge Search |
| Chat with AI | AI → AI Workspace |
| Review findings | Quality → Findings |
| Manage users | Administration → Users |
| View reports | Analytics → Reports |

## Home dashboard

Home now shows a concise executive view:

- **Compliance Rate**, **Open Findings**, **Audits This Month** — currently
  **Demo data** (clearly labelled).
- **Quick Actions** — one-click links to Run AI Audit, Browse Knowledge, View
  Reports, and Ask AI.

Demo figures are placeholders until your institution's real QA data is onboarded.
