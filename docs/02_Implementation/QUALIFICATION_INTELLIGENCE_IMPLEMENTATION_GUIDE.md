# Qualification Intelligence — Implementation Guide

## Overview

The Qualification Intelligence subsystem provides advisory GPA/CGPA calculation, percentage-to-grade conversion, credit aggregation, and NQF level mapping. All outputs are clearly marked as advisory and must NOT be presented as official SAQA determinations.

## Architecture

```
POST /qualification-intelligence/calculate   ← stateless calculation (no DB)
POST /qualification-intelligence/records     ← calculate + persist
GET  /qualification-intelligence/records     ← list user's records
GET  /qualification-intelligence/records/{id}
DELETE /qualification-intelligence/records/{id}
GET  /qualification-intelligence/records/{id}/export/csv
```

All endpoints require any authenticated staff role (`AnyAuthenticatedUser`). Records are user-scoped — users cannot see each other's records.

## GPA Conversion Scale

South African HEQSF-aligned 4.0 scale (advisory):

| Percentage | Letter | Grade Points |
|-----------|--------|-------------|
| 80–100 | A | 4.0 |
| 75–79 | A- | 3.7 |
| 70–74 | B+ | 3.3 |
| 65–69 | B | 3.0 |
| 60–64 | B- | 2.7 |
| 55–59 | C+ | 2.3 |
| 50–54 | C | 2.0 |
| 45–49 | C- | 1.7 |
| 40–44 | D | 1.0 |
| 0–39 | F | 0.0 |

Pass mark: 50% (HEQSF standard).

## GPA Formula

```
GPA = Σ(grade_points_i × credits_i) / Σ(credits_i)
```

CGPA is computed as credits-weighted average of per-semester GPAs.

## NQF Advisory Mapping

| Qualification Type | Advisory NQF Level | Minimum Credits |
|--------------------|--------------------|----------------|
| `certificate` | 5 | 120 |
| `diploma` | 6 | 240 |
| `bachelor` | 7 | 360 |
| `honours` | 8 | 120 |
| `masters` | 9 | 180 |
| `doctoral` | 10 | 360 |

The advisory level is derived from the `qualification_type` field in the request. If the actual credit total is below the minimum, a warning and credit gap are included in the response.

## Calculation Pipeline

```python
# qualification_service.py
entries: list[SubjectEntry]  # from request

subjects = calculate_subject_results(entries)   # adds letter_grade, grade_points, quality_points, passed
semester_gpas = calculate_semester_gpas(subjects)  # per-semester GPA breakdown
gpa = calculate_gpa(subjects)                    # weighted across all subjects
cgpa = calculate_cgpa(semester_gpas)             # weighted across semesters
nqf = advisory_nqf_level(total_credits, qualification_type)
summary, warnings, recs = generate_advisory_report(...)

return CalculationResult(...)  # fully populated result
```

## DB Model

`qualification_records` table:
- `user_id` (FK → users.id, CASCADE)
- `student_name`, `institution_name`, `programme_name`, `qualification_type`
- `total_credits`, `gpa`, `cgpa`
- `nqf_advisory_level`, `nqf_advisory_label`
- `entries` (JSONB — list of SubjectEntry dicts)
- `calculation_result` (JSONB — full CalculationResult dict)
- Standard `id`, `created_at`, `updated_at`

## CSV Export

`GET /qualification-intelligence/records/{id}/export/csv` returns a UTF-8 BOM CSV with:
1. Header block (student info, GPA, NQF advisory)
2. Subject breakdown table
3. Advisory summary, warnings, recommendations
4. Full disclaimer footer

## Disclaimer

Every response, every export, every page renders the following disclaimer:

> ADVISORY ONLY — This report is generated by the AQAA Qualification Intelligence tool for internal advisory purposes. It does NOT constitute an official SAQA qualification evaluation, recognition of prior learning determination, or any formal academic credential assessment. Contact SAQA or the relevant Quality Council for official evaluations.

This disclaimer is embedded in the `CalculationResult.disclaimer` field and cannot be suppressed.

## Adding a New Qualification Type

1. Add to `_QUAL_TYPE_TO_LEVEL` dict in `qualification_service.py`
2. Add to `_NQF_NORMS` list with level, label, type string, and minimum credits
3. Add to `QUAL_TYPES` list in `QualificationIntelligenceView.tsx`
4. Add test in `test_qualification.py`
